About

What is GermanReady?

GermanReady is a mobile-first test prep and vocabulary app for people preparing for the official Leben in Deutschland integration test (Einbürgerungstest). Unlike the sparse official app, GermanReady layers bilingual support, vocabulary coaching, and clean UX on top of the full 310-question bank.

Every question comes with an inline vocabulary keyword table — German word, grammatical article, IPA phonetics, and English translation. You're not just drilling answers. You're learning the language needed to understand them.

🇩🇪 Einbürgerungstest candidates 💑 Spouses doing A1/A2 family reunification 🏫 BAMF integration course students 📚 Self-learners entering German 🌍 Pakistani · Turkish · Arabic diaspora

Setup

Get running locally.

1

Clone the repo

Private repo — make sure your SSH key is added to GitHub first.

2

Install Python dependencies

Requires Python 3.10+. Run from project root.

# clone
git clone git@github.com:frauikram/germanready-app.git
cd germanready-app

# install deps
pip install kivy kivymd peewee --break-system-packages

# run on desktop (for dev/testing)
python app/main.py
# data pipeline (separate repo)
pip install spacy deepl epitran pandas --break-system-packages
python -m spacy download de_core_news_sm

# seed the database
python data-pipeline/seed_db.py --source bamf_questions.pdf
# android build (requires buildozer + Docker recommended)
buildozer android debug

# deploy to connected device
buildozer android deploy run logcat
